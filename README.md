# 🏋️‍♂️ Gym-Up (In Development)

**Gym-Up** is a gamified workout tracker designed to help you level up your fitness journey. Built with a decoupled architecture, it combines a robust Laravel API with a responsive Vanilla JS frontend.

## 🚀 Tech Stack

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3.
* **Backend:** Laravel 12 (PHP) [API Only].
* **Database:** MySQL.
* **Tools:** VS Code Live Server, Laragon/XAMPP (Preferably Laragon)

## Key Features

### 1. Exercise Management (CRUD)
* **Create:** Add new custom exercises with muscle group & equipment details.
* **Read:** Browse exercises with search and category filters.
* **Update:** Edit exercise details directly from the catalog.
* **Delete:** Remove exercises with confirmation protection.

### 2. Workout Logging
* **Real-time Tracking:** Log sets, reps, and weight instantly.
* **Rest Timer:** Built-in timer between sets.
* **History:** (Coming Soon) Track your progress over time.

### 3. Gamification & Nutrition
* **RPG Elements:** Database structure ready for XP, Levels, Ranks, and Streak. (Coming soon)
* **Nutrition Goals:** Bulking, Cutting, and Maintenance calorie targets based on users' measurements. (Coming soon)

### 4. Custom UI/UX
* **Dark Mode:** Sleek dark aesthetic with Gold accents.
* **Custom Alerts:** Replaced browser defaults with animated, custom-styled modals for success/error messages.
* Hybrid approach between Single page app and Multi Page app for versatility, easier load, easier development and of course, easier usage
